# Welcome

This is your new blog. It runs on **GoMark**, a tiny self-hosted Markdown blog,
and this post is just here to get you started.

## Writing

Every `.md` file in the `posts/` directory becomes a post. The filename is the
URL slug, so `welcome.md` is served at `/posts/welcome`. Add optional front
matter at the top of the file:

```markdown
---
title: My First Post
tags: go, web
date: 2026-01-31
---

Your content goes here.
```

Posts are reloaded automatically when you save a file, so you can write and see
the result without restarting the server.

## Next steps

- Delete this post when you are done reading it.
- Add your own Markdown files to `posts/`.
- Search and tag filters are on the home page, and an RSS feed lives at `/feed.xml`.

Happy writing!
